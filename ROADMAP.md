# The plan, in plain English

## The one idea
We are not sitting through a long course. We are building 12 real AI programs,
one after another, easiest first. The learning comes from building each one.
Short videos only help with the build in front of us.

## What this repo is
Your workshop and your showroom at the same time.
- Workshop: where the code for every project lives while you build it.
- Showroom: when a recruiter, client or employer asks "what can you build?",
  you send this link. The projects are the proof behind your resume.

## What goes inside
One folder per project under `projects/`. Every finished project has 4 things:
1. The code
2. A one page explanation: what it does, with a simple diagram
3. Test or evaluation results: proof it actually works, and how well
4. Demo notes: how to run it, what it costs to run

## What is inside right now
`src/hello_agent` is the smallest possible agent: it takes a question,
decides to use a tool (a calculator), gets the result, and answers.
That pattern, a system that uses tools to do work instead of only chatting,
is the seed of everything else in this repo. Each project below is that
same pattern, bigger and more useful.

## The 12 projects, and what each one teaches you
1. Research Agent: searches, reads sources, writes a report with citations.
   Teaches: planning, tool use, checking sources.
2. MCP Tool Server: a standard plug that gives any agent new tools.
   Teaches: MCP, the current standard for connecting agents to tools.
3. Support Triage Agent: reads customer messages, sorts and routes them.
   Teaches: structured outputs, routing, reliability.
4. Enterprise RAG: answers questions from a pile of documents, accurately.
   Teaches: search over documents, embeddings, measuring answer quality.
5. Analyst Agent: answers questions from data, writes its own queries.
   Teaches: agents working with databases.
6. Research Crew: several agents working as a team on one job.
   Teaches: multi agent teamwork with CrewAI.
7. Engineering Team: planner, coder, reviewer and tester agents.
   Teaches: agent teams that build and check software.
8. Workflow Agent: automates a repetitive office workflow end to end.
   Teaches: connecting agents to real business tools.
9. Bedrock Agent: Project 1 rebuilt to run in production on AWS.
   Teaches: running agents live, cost control, security, monitoring.
10. Azure Agent: the same discipline on Microsoft Azure AI Foundry.
    Teaches: the second big cloud, so you are not locked to one vendor.
11. Secure Agent Platform: a reusable base a company can run many agents on.
    Teaches: enterprise architecture, identity, audit, safety.
12. Capstone: one product you can sell, built on Primus Cloud Solutions.
    Teaches: turning all of the above into money.
