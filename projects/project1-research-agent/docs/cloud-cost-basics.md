# Cloud cost basics for AI systems
The biggest cost in most AI systems is model usage, charged per token.
Long prompts and long answers cost more, so keeping context tight and
routing simple questions to smaller models saves real money.
The second cost is search and storage for document systems, which is
usually small next to model spend. A monthly budget cap and a weekly
cost review keep experiments from surprising you.
Caching repeated answers and batching work where possible also cut
cost without hurting quality.
