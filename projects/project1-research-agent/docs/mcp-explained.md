# MCP explained
MCP, the Model Context Protocol, is a standard way to connect agents
to tools and data. Before MCP, every tool needed a custom integration
for every agent framework. With MCP, a tool is built once as an MCP
server and any MCP client agent can use it.
Think of MCP like USB for AI tools: one plug shape that works
everywhere. MCP servers can offer tools, resources and prompts.
MCP was introduced by Anthropic and is now adopted across the major
AI platforms, including OpenAI, Google and Microsoft tools.
