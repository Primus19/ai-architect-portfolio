# What is an agent
An agent is a system that does work, not just talk. It takes a goal,
decides on steps, uses tools such as search, calculators or databases,
checks what came back, and continues until the task is done.
A chatbot answers from its training. An agent acts: it can look things
up, run code, and change files or records through its tools.
The control loop is always the same: think, act with a tool, observe
the result, then decide the next step.
